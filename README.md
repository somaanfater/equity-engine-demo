# Equity Research Engine — public demo

Rendered output only. This repository contains **no engine source, no prompts, no
configuration and no keys** — only the static site and the JSON/HTML the engine produces.

- Numbers-only reports are the computation layer alone (no AI narrative) and are rebuilt
  each weekday by a scheduled job on the author's machine, which commits here and triggers
  a redeploy.
- The flagship full report is a one-off AI run, kept as a fixed artefact.

**Demo — not offered for sale. Educational, not investment advice.**
