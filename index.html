Two ideas the rest of the category skips

01, Provenance as interface

A number you cannot trace is a number you cannot use.

Most finance products show you a figure and expect you to trust the vendor. Here, every ruled number carries its origin: the filing and Item section it was read from, or the named function and formula that produced it. Nothing in the analysis layer can invent a figure, because the model is never asked to produce one, it requests computations through tool calls and reasons over the results.

Try it: hover this illustrative number Example This one is a demonstration of the interaction, not a figure from a filing, which is why it carries no value and no citation. Every real provenance mark names the module that computed it or the filing section it was read from. See any ticker report for live ones anywhere on the site.

02, Visible confidence

A point estimate is a claim about precision you probably cannot make.

Fair value is a distribution rather than a single number, so it is drawn as one. Bands show the simulated P10–P90; the tick is the point estimate and the hairline is the market price. Where the council disagrees, you see the split rather than an averaged-away consensus. A wide band renders its figure in a lighter weight: the typography carries the uncertainty instead of hiding it.
